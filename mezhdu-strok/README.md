# Между строк

Русскоязычный MVP поиска связей в любимых вещах. Снимок опубликованной версии проекта, исходный коммит Sites: 740392c475bb1e680725d58566fbe852f01ec808.

Сайт: https://mezhdu-strok-patterns.aygul-parskaya.chatgpt.site

## Структура

- `dist/` — текущий интерфейс с десятью вопросами, демонстрационным результатом и скачиванием PNG 1080 × 1350.
- `server/` — подготовленный Worker для последовательного анализа и проверки критиком. В опубликованной статической версии AI ещё не подключён.
- `.openai/hosting.json` — идентификатор существующего сайта Sites.

## Локальный запуск

Для интерфейса: `python -m http.server 8000 --directory dist`.

Для Worker: `npm install`, затем `npm run dev`. Для настоящего анализа настройте `OPENAI_API_KEY` как секрет; не храните ключ в Git. `OPENAI_MODEL` необязателен.

`npm run check` проверяет синтаксис JavaScript.
