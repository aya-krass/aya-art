# Между строк — MVP

Человек пишет, что любит в разных сферах жизни. AI находит повторяющиеся связи и показывает их коротко и красиво. Это наблюдение, а не диагноз.

## Экраны

1. Landing → 2. Форма (9 вопросов, теги, скриншоты) → 3. Загрузка → 4. Главный инсайт → 5. Паттерны → 6. Неожиданные пары → 7. «По той же причине…» → 8. Share card (PNG 1080 × 1350).

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html`, `styles.css` | Экраны и визуальный язык: ivory, чёрный, кармин, золото; коллаж из рваной бумаги, бархата, брызг, букв-вырезок |
| `app.js` | Логика экранов, счётчик вещей (минимум 12), черновик в localStorage, отправка на анализ |
| `prompts.js` | Промпт 1 (анализ), промпт 2 (критик), JSON-схема. Единственное место с алгоритмом |
| `api/analyze.js` | Серверная функция: два последовательных вызова Claude, ответ в JSON |
| `collage.js` | Рваные края, брызги краски, буквы-вырезки |
| `sharecard.js` | Отрисовка share card на canvas |
| `demo.js` | Пример ответов и результата для демо и рила |

## Запуск

**Только посмотреть (без AI):** открой `index.html?demo` через любой статический сервер. На GitHub Pages это `…/mezhdu-strok/?demo`. В форме есть «Заполнить примером».

**Ручной тест (как в ТЗ):** в форме нажми «Скопировать промпт для ручного теста». Вставь его в новый чат Claude. Потом нажми кнопку ещё раз, чтобы скопировать промпт 2, и отправь его следующим сообщением.

**Полная версия с AI (Vercel):**
1. Импортируй репозиторий в Vercel и укажи Root Directory `mezhdu-strok`.
2. В Environment Variables добавь `ANTHROPIC_API_KEY`.
3. Deploy. Функция `api/analyze` поднимется сама.

Модель: `claude-opus-5-5`, adaptive thinking, effort `high`. Её можно сменить через переменную `ANTHROPIC_MODEL`. Если модель отказывается отвечать, server-side fallback отправляет тот же запрос другой модели.

## Настройки

- `ENABLE_SAME_REASON` в `prompts.js`: `false` убирает блок «По той же причине…» из промпта, схемы и экранов.
- `CONFIG.shareUrl` в `app.js`: URL для футера share card (открытое решение №2). Если пусто, берётся текущий домен.
