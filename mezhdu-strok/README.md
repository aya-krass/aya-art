# Между строк

Русскоязычный MVP: неожиданные доказуемые связи в любимых вещах.

Сайт: https://mezhdu-strok-patterns.aygul-parskaya.chatgpt.site

## Версия

Девять текстовых вопросов; без отдельного цвета, скриншотов и рекомендаций. Главный инсайт → 2–4 паттерна → 2–4 пары → PNG 1080 × 1350. Основной текст инсайта тёмный; ключевой фрагмент подчёркнут золотом. Доказательства раскрываются по «Почему?».

Analyst ищет 8–12 кандидатов, если данные позволяют; Critic отбирает лучшие. Главный инсайт содержит 25–45 слов и минимум три доказательства из трёх исходных сфер. Количество сфер вычисляется в коде. Анализ отсутствующих предпочтений запрещён.

## Структура

- `dist/index.html`, `dist/app.js`: интерфейс и явно обозначенный демонстрационный результат.
- `server/`: Analyst → Critic и проверка результата.
- `build.mjs`: сборка автономного Cloudflare Worker в `dist/server/index.js`.
- `docs/requirements-v3.md`: требования пользователя.
- `tests/server.test.mjs`: проверки формата, доказательств и последовательных вызовов.

## Запуск

`npm run build` и `npm run check` не требуют установки зависимостей. `node --test tests/server.test.mjs` запускает тесты после сборки.

Для разработки с Worker: `npm install`, затем `npm run dev`. Настройте `OPENAI_API_KEY` в секретах среды или локальном игнорируемом `.dev.vars`. Не добавляйте ключ в Git. Опциональный `OPENAI_MODEL` — `gpt-4.1` по умолчанию.

Без ключа сервер возвращает понятную ошибку 503, сохраняющую ответы в текущей вкладке. Тест последовательных вызовов использует подменённые ответы, а не реальную модель: он проверяет работу кода, но не качество анализа.

## Проверка качества с людьми

После настройки ключа пять разных людей независимо заполняют форму. Сначала показать результат и 30 секунд не объяснять. Затем спросить: «Какую связь ты увидел?», «Ты раньше так связывал эти вещи?», «Почему эти примеры подходят или не подходят?», «Какую пару ты бы отправил другому человеку?».

Критерий: «Я бы сам так эти вещи не связал, но когда это показали — я вижу, почему это имеет смысл». Ответ «похоже на меня» недостаточен. Сравнить пять главных инсайтов: они не должны быть взаимозаменяемыми. Реальный тест с участниками пока не проведён.
